# 04 — Flashcards

Status: DRAFT

## 1. Purpose
The Flashcard system helps students study via spaced repetition or direct review. Instead of manual data entry, flashcards are automatically generated by AI based on the summaries of uploaded PDF documents. 

## 2. Requirements
- FR-4.1 Create flashcard (Automated via AI processing of a Document Summary)
- FR-4.2 Edit flashcard (To correct AI mistakes or refine)
- FR-4.3 Delete flashcard
- FR-4.4 View flashcards by document/subject

## 3. Data model
### `Flashcard`
- `id`: UUID (Primary Key)
- `user`: ForeignKey to `User` (on_delete=CASCADE, index)
- `document`: ForeignKey to `documents.Document` (on_delete=CASCADE, related_name="flashcards", index)
- `question`: TextField()
- `answer`: TextField()
- `created_at`: DateTimeField(auto_now_add=True)
- `updated_at`: DateTimeField(auto_now=True)

*(Note: We tie flashcards directly to the `Document` they were generated from, which acts as the "Subject" or "Deck" for those cards).*

## 4. API endpoints
Base path: `/api/v1/`
Auth: Required (`IsAuthenticated`)

### `POST /documents/{id}/generate_flashcards/`
Trigger AI generation of flashcards for a specific document.
Response: 202 Accepted.
*Side-effect:* Queues a Celery task that reads the document's summary, prompts the AI to generate Q&A pairs, and creates `Flashcard` records. If flashcards already exist for this document, it can either clear them or append to them (append is safer, but returning a 400 if they already exist might prevent duplicates).

### `GET /flashcards/`
List flashcards for the authenticated user.
Query params:
- `document={uuid}` (Filter flashcards by the source document/subject)
Response: 200 OK (Paginated list)

### `PATCH /flashcards/{id}/`
Edit a specific flashcard (e.g., if the user wants to fix an AI-generated question/answer).
Request: `{ question?, answer? }`
Response: 200 OK

### `DELETE /flashcards/{id}/`
Delete a specific flashcard.
Response: 204 No Content

## 5. Business rules
- Flashcards are generated asynchronously. The generation endpoint is only available if the `Document` has a status of `DONE` (meaning the summary exists).
- To prevent spamming the AI, the `generate_flashcards` endpoint should reject requests if the document already has generated flashcards, or rate-limit strictly.
- A user can only view, edit, or delete their own flashcards.

## 6. Security & permissions
- All endpoints require authentication (`IsAuthenticated`).
- Viewsets must filter querysets: `Flashcard.objects.filter(user=request.user)`.
- Generating flashcards requires ownership of the referenced `Document`.
